# Museeve — logo exploration, batch 1

**Date:** 2026-08-11 · **Tool:** LoveArt · **Goal:** discover territory, not pick a winner.

Ten prompts, ten *different strategies* — not ten skins of one idea. The point of batch 1 is
to find which direction the client leans toward; batch 2 goes deep on the one or two that land.

## Brand inputs these are built from

| Input | Value |
|---|---|
| Name | **Museeve** — the only name. Roots: *Muse* + the doubled *ee* |
| "Music Everywhere" | Placeholder lockup in the Figma file. Not the brand, not a tagline. Ignore it |
| Palette | crimson `#8B1C1C` · near-black `#141414` · warm off-white `#D6CCCC` · blush `#F7D8D8` |
| Display type | Beautique Display Bold — high-contrast serif, letter-spacing −1 |
| Body type | DM Sans |
| Mood in the Figma file | dark, satin/velvet, luxury-editorial. Nightclub and opera house, not SaaS |
| Audiences | Fan · Artist · Institution (venues, schools, labels) |
| Stakes | app moves real money (Stripe payouts, rentals, subscriptions) — mark must read trustworthy, not playful |

**Naming reads worth designing against.** *Muse* — the classical root, patron of the art
(territory 04). *Museeve* — the doubled `ee` is the one letterform event no competitor owns
(territory 02). *M* — the carrier for everything else. All three are in this batch on purpose.

## How to run the batch

- One prompt per generation, 1:1 square, keep the seeds — a good seed re-rolled at a
  different stroke weight is batch 2's starting point.
- Judge each at **24 px** and in **pure black on white** before judging it at full size in colour.
  A mark that only survives in crimson on black is not a logo, it's a hero image.
- Bring back: which ones the client points at *first*, and what word they use for it.
  The word matters more than the pick.
- AI renders lettering unreliably. 01–09 are mark-only on purpose. Expect to redraw the
  winner as real vectors — these generate *direction*, not production files.

## 01 — Arch monogram (the safe anchor)

*Territory: architectural, institutional, permanent. Tests whether the client wants gravitas.*

```
Flat vector logo mark: a capital letter M constructed from two identical pointed arches,
like the proscenium arch of a concert hall repeated twice. The central vertex of the M drops
lower than the outer stems, forming a subtle downbeat. Built on a strict geometric grid with
a single uniform stroke weight, sharp mitered joints, no tapering. Solid shapes only.
Two colors: deep crimson #8B1C1C mark on a flat near-black #141414 square. Centered,
generous margin, symmetrical.
No text, no letters other than the M, no musical notes, no gradient, no shadow, no bevel,
no 3D, no mockup, no business card, no sparkles, no swoosh.
```

## 02 — The double-E ligature

*Territory: luxury fashion house, built on the one thing only this name has — the doubled `ee`.
Tests the high-contrast serif already in the Figma file.*

```
Flat vector monogram: two capital letter E's facing each other back to back, fused into one
symmetrical ligature that shares a single continuous middle crossbar running all the way
through both. The result is a closed, badge-like glyph with strong horizontal rhythm.
High-contrast Didone construction — hairline thin horizontals against very thick vertical
stems, sharp unbracketed serifs. Precise, editorial, luxury fashion-house feeling. Solid
single color: warm off-white #D6CCCC on flat near-black #141414. Centered, wide margin.
No other letters, no words, no tagline, no musical notes, no gradient, no shadow, no 3D,
no mockup, no ornament, no frame.
```

**02b — same idea, mirrored instead of back-to-back.** Run both, they read very differently:

```
Replace the first sentence with: two capital letter E's side by side facing the same
direction, the second E overlapping the first so that the first E's stem is hidden and only
one shared vertical spine remains, reading as a single doubled letterform.
```

## 03 — Pin × signal (the literal "everywhere")

*Territory: place + sound. The most product-descriptive route; also the most crowded.*

```
Flat vector logo mark: a map pin whose circular head is cut away by negative space into three
concentric arcs, open on the right side, so the shape reads simultaneously as a location pin
and as sound radiating outward. One uniform stroke weight throughout, perfect circles,
45-degree geometry, mathematically constructed. Solid two-tone: deep crimson #8B1C1C on flat
near-black #141414. Centered, generous margin.
No text, no dot at the base of the arcs, no wifi icon, no gradient, no glow, no shadow,
no 3D, no mockup.
```

## 04 — Lyre, neoclassical

*Territory: the "Muse" half of the name. Heritage, culture, institutions. Brass instead of crimson — deliberate palette stress test.*

```
Flat vector emblem: an abstract lyre reduced to five vertical strings of varying height inside
a rounded arch, the arch open at the bottom. Neoclassical proportion, drawn with a single
hairline stroke weight, extremely restrained — an opera house program cover, not an
illustration. Antique brass #B08D57 lines on flat deep oxblood #3A0D0D. Centered, wide margin,
perfectly symmetrical.
No text, no laurel wreath, no cherub, no face, no filigree, no texture, no gradient,
no shadow, no 3D, no mockup.
```

## 05 — Satin fold

*Territory: the material already in the product (the satin video background) becomes the mark.*

```
Flat vector logo mark: a single continuous ribbon of satin folded once into a shape that reads
as the letter M, drawn as flat solid shapes with hard-edged facets where the fold catches
light. Two flat tones of crimson only — #8B1C1C and #5A1010 — to imply the fold, on flat
near-black #141414. Bold closed silhouette that survives at 24 pixels. Centered, generous
margin.
No rendering, no photographic realism, no gradient mesh, no fabric photograph, no text,
no shadow, no glow, no 3D render, no mockup, no award ribbon or rosette.
```

## 06 — Vinyl aperture

*Territory: negative-space craft. Two meanings in one shape — record and aperture, listening and capturing.*

```
Flat vector logo mark: a filled circle with a smaller concentric circle removed at the center,
and six straight radial cuts of negative space slicing inward from the outer edge at even
intervals, stopping short of the center — reading simultaneously as a vinyl record and a
camera aperture. Strict rotational symmetry, mathematically even gaps, no perspective.
Single solid color: warm off-white #D6CCCC on flat near-black #141414. Centered, wide margin.
No text, no groove detail, no label artwork, no gradient, no shadow, no reflection, no 3D,
no mockup.
```

## 07 — Swiss modular

*Territory: industrial-technical, light surface. The opposite pole from 04 — tests whether the client actually wants the dark luxe or has just been shown it.*

```
Flat vector logo mark: the letter M constructed from only three shapes — two quarter-circle
arcs and one vertical bar — snapped to a 4×4 modular grid, in the manner of a 1970s Swiss
corporate identity manual. Uniform stroke terminals cut at 90 degrees, no optical adjustment,
unapologetically mechanical. Single solid color: deep crimson #8B1C1C on flat bone white
#F2EFEA. Centered, generous margin.
No text, no visible grid lines in the final mark, no gradient, no shadow, no 3D, no mockup,
no ornament.
```

## 08 — Contour

*Territory: sound as terrain — "everywhere" as coverage. Quietest of the ten; scales worst. Included to see if anyone reaches for it.*

```
Flat vector logo mark: seven nested closed contour lines, like a topographic map of a single
hill, where the innermost contour is a perfect circle and each outer ring distorts
progressively into a waveform ripple. Even line weight, even spacing, no fill between the
lines. Single color: blush #F7D8D8 on flat near-black #141414. Square composition, centered,
generous margin.
No text, no numbers, no map labels, no coastline, no gradient, no shadow, no 3D, no mockup.
```

## 09 — Ink gesture

*Territory: human, performed, imperfect. Nothing else in the batch has a hand in it.*

```
Flat vector logo mark: a single confident brush stroke, made in one gesture, that turns back
on itself to form the letter M, with a dry-brush break in the middle of the second stroke.
Real ink character — pressure variation, one slightly frayed terminal — but reproduced as flat
solid vector shapes. Pure black #141414 on flat bone white #F2EFEA. Centered, generous margin,
asymmetrical and alive.
No texture image, no photograph, no gray tones, no text, no calligraphy characters from any
writing system, no splatter, no gradient, no shadow, no 3D, no mockup.
```

## 10 — Wordmark

*Territory: no symbol at all. Tests whether the name can carry the brand alone — cheapest identity to build and the hardest to get right.*

```
Flat vector wordmark, one word: MUSEEVE. Set in a high-contrast display serif with a
pronounced italic slant, sharp unbracketed serifs, very thin hairlines against heavy stems.
The two adjacent E's in the middle share a single crossbar, joining as a ligature. Tight
letter spacing, all capitals, baseline perfectly level. Spell it with exactly seven letters:
M U S E E V E. Single solid color: warm off-white #D6CCCC on flat near-black #141414.
Centered, wide margin.
No symbol, no icon, no tagline, no second line of text, no underline, no gradient, no shadow,
no 3D, no mockup.
```

**10b — lowercase.** Museeve has three ascender-free letters in a row (`u s e`) and a doubled
`ee`; lowercase makes the name look like a word rather than an acronym. Worth one roll:

```
Replace "all capitals" with: all lowercase, no capital letters at all, including the first
letter. The two adjacent e's share a single crossbar. Spell it: m u s e e v e.
```

## What batch 2 does with the result

Once one or two territories land:

1. Re-run the winner at **three stroke weights** and **two proportions** (wider/narrower) — same seed.
2. Force it through the failure tests: 24 px, single-colour black, single-colour white knocked
   out of crimson, and inside a squircle app-icon safe area.
3. Only then pair it with the wordmark and build the lockup.
4. Redraw in vectors. Nothing generated here ships as-is.
