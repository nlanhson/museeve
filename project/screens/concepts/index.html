What goes on each screen

Every screen below comes in three directions, side by side, so you can point at the one that feels right. Each set names our recommendation; there is no wrong answer to react to. All of it is built from the colors, type, and components validated in the wireframe file. Where the wireframe borrowed from familiar social apps, these push toward patterns the music world already owns — a concert programme, a record shelf, a membership card, and the box office the wireframe never drew. Nothing here looks like a photo-sharing app, on purpose.
